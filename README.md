# 🧱 블록월드 어드벤처

초등학생을 위한 브라우저 3D 복셀 샌드박스 게임.
**파일 하나(`index.html`)만 열면 바로 실행됩니다.** 설치도, 빌드도, 로그인도 필요 없습니다.

## 놀아보기

`index.html` 을 더블클릭하거나 브라우저에 끌어다 놓으면 끝!
(인터넷 연결 필요 — 3D 엔진 Three.js를 CDN에서 불러옵니다.)

## 조작법

마우스 없이 **키보드만으로도** 전부 할 수 있습니다.

| 키 | 하는 일 |
|---|---|
| `W A S D` | 움직이기 |
| `스페이스` | 점프 |
| `← ↑ ↓ →` | 둘러보기 |
| `Q` | 블록 부수기 |
| `E` | 블록 놓기 |
| `1`~`8` | 블록 고르기 |

마우스를 쓰고 싶으면 화면을 한 번 클릭하세요. 그다음부터 마우스로 둘러보고
왼쪽 클릭으로 부수고 오른쪽 클릭으로 놓을 수 있습니다. (`Esc` 로 해제)

모바일은 왼쪽 조이스틱 + 오른쪽 버튼으로 조작합니다.

## 기술

- Three.js (CDN), 단일 HTML 파일, 인라인 CSS/JS
- 외부 이미지·사운드 파일 없음 — 그래픽은 캔버스로 그리고 소리는 Web Audio로 합성
- 진행 상황은 브라우저 `localStorage`에 저장
