# 🦤 도도블록

> 멸종된 도도새들이 모여 사는 신비의 블록섬

초등학생을 위한 브라우저 3D 복셀 샌드박스 게임.
주인공은 날지 못하는 뚱뚱하고 귀여운 도도새 — 뛸 때마다 몸이 풀썩 눌렸다 쭈욱 펴집니다.
**파일 하나(`index.html`)만 열면 바로 실행됩니다.** 설치도, 빌드도, 로그인도 필요 없습니다.

## 놀아보기

`index.html` 을 더블클릭하거나 브라우저에 끌어다 놓으면 끝!
(인터넷 연결 필요 — 3D 엔진 Three.js를 CDN에서 불러옵니다.)

## 웹에 올리기

친구에게 파일을 보내는 대신 **주소 하나만** 보내고 싶다면, Cloudflare Pages 에 올립니다.

```bash
npx wrangler login     # 처음 한 번만
./publish.sh
```

끝나면 **https://dodoblock.pages.dev** 에서 게임이 열립니다. 그 주소를 아는 사람은
누구나 들어올 수 있으니, 공개해도 되는지 먼저 생각하고 올리세요.
`publish.sh` 는 `index.html` 하나만 올립니다 (`server/` 는 안 올라갑니다).

⚠️ Cloudflare 프로젝트의 **production branch** 와 같은 이름으로 올려야 그 주소에
뜹니다. 다른 이름으로 올리면 아무도 안 보는 미리보기 자리에 올라갑니다.
`publish.sh` 는 지금 있는 가지 이름을 그대로 씁니다 (`./publish.sh main` 처럼
직접 정할 수도 있습니다).

💬 대화 서버는 따로입니다 — `server/README.md` 를 보세요.

## 조작법

마우스 없이 **키보드만으로도** 전부 할 수 있습니다.

| 키 | 하는 일 |
|---|---|
| `W A S D` | 움직이기 |
| `스페이스` | 점프 |
| `← ↑ ↓ →` | 둘러보기 |
| `Q` | 블록 부수기 |
| `E` | 블록 놓기 |
| `1`~`8` | 블록 고르기 |
| `9` `0` | 제작한 특별 블록 고르기 |
| `Z` | 되감기 — 실수한 블록 되돌리기 |
| `C` | 제작대 |
| `B` | 청사진 건축학교 |
| `V` | 배지 |
| `G` | 친구 초대 |
| `I` | 🏝️ 내 섬 — 꾸미기 · 섬 이름 · 자랑 카드 · 섬 코드 |
| `Shift`+`R` | 🎥 녹화 시작 / 멈추기 |
| `Tab` | 🎒 도도 가방 (나머지 기능 전부) |

🎒 도도 가방 → **🛠️ 도도 스튜디오** 로 들어가면 조작이 달라집니다.

| 스튜디오 키 | 하는 일 |
|---|---|
| `E` / `Q` | 날면서 위 / 아래로 (`Shift` 로 빠르게) |
| `V` | 🕊️ 날기 켜기 / 끄기 |
| `R` / `F` | 블록 놓기 / 부수기 |
| `Tab` | 단계 넘기기 (1 판 짓기 → 2 규칙 → 3 꾸미기) |
| `G` | 🎯 이기는 방법 정하기 |
| `P` / `Shift`+`P` | ▶ 처음부터 / 📍 여기서부터 해보기 |
| `T` | 🪶 도도AI 입력칸으로 (화면이 넓으면 왼쪽에 늘 떠 있습니다) |
| `Esc` | 스튜디오에서 나가기 (저절로 저장) |

마우스를 쓰고 싶으면 화면을 한 번 클릭하세요. 그다음부터 마우스로 둘러보고
왼쪽 클릭으로 부수고 오른쪽 클릭으로 놓을 수 있습니다. (`Esc` 로 해제)

모바일은 왼쪽 조이스틱 + 오른쪽 버튼으로 조작합니다.
화면이 좁으면 칸마다 작은 **`▾` 접기 단추**가 생깁니다 — 🪙 코인·레벨 ·
📋 퀘스트 · 🧱 블록 바 · ⚙️ 오른쪽 동그란 단추들을 하나씩 접었다 펼 수 있고,
접은 상태는 기억합니다. 접어도 제목이나 지금 고른 블록은 남아서 어디 있었는지
알 수 있습니다.

## 무엇을 할 수 있나

### 🛠️ 도도 스튜디오 — 아이가 게임을 만든다
시작 섬은 **시작 화면**입니다. 도도블록의 핵심은 아이가 **직접 게임을 만들어
친구에게 보내는 것**입니다. 🎒 도도 가방 → 🛠️ 도도 스튜디오 에서 시작합니다.

#### 만들 수 있는 게임 8가지
게임을 새로 만들 때 **장르**를 먼저 고릅니다. 장르를 고르면 세 가지가
한꺼번에 바뀝니다 — 2 규칙 단계의 블록 바, 이기는 방법, 도도AI가 깔아 주는 기본 판.

| 장르 | 어떤 게임 | 이기는 방법 |
|---|---|---|
| 🧗 점프맵 | 발판을 뛰어서 골인까지 | 🏁 골인 |
| 💎 보물찾기 | 숨긴 코인을 다 모으기 | 🪙 다 모으기 |
| 🌀 미로·방탈출 | 열쇠를 찾아 문을 열고 나가기 | 🏁 골인 |
| ⚡ 피하기 | 깜빡이는 함정을 피해 버티기 | ⏱️ 버티기 |
| 🏃 달리기 시합 | 시간 안에 결승선까지 | 🏁 골인 |
| ❓ 퀴즈 | 문제를 읽고 ⭕ ❌ 중에 밟기 | ❓ 다 맞히기 |
| 🦤 숨바꼭질 | 숨은 도도를 다 찾아내기 | 🦤 다 찾기 |
| 🎈 물풍선 맞히기 | 물풍선을 던져 과녁을 맞히기 | 🎯 과녁 다 맞히기 |
| 🎨 자유롭게 | 마음대로 — 블록을 다 꺼내 씁니다 | 아무거나 |

장르는 **꾸러미일 뿐**이라 언제든 다른 블록을 섞어도 되고,
도도AI에게 "퀴즈 만들어 줘" 라고 말하면 만드는 도중에도 장르가 통째로 바뀝니다.

만드는 순서는 3단계입니다. 단계를 고르면 아래 블록 바가 통째로 바뀝니다.

1. **🧱 판 짓기** — 날아다니며 블록을 쌓습니다. 뛰어서 못 닿는 자리에 발판을
   놓으면 *놓는 순간* 알려 줍니다.
2. **🎯 규칙** — **마법 블록 14종**을 놓고 이기는 방법을 정합니다.
   🚩 시작점 · 🏁 골인 · 🪙 코인 · ⭐ 별 · ☠️ 함정 · 🔑 열쇠 · 🚪 문 ·
   💬 표지판 · 🔵 체크포인트 · ⏳ 사라지는 발판 · ⚡ 깜빡 함정 ·
   🦤 숨은 도도 · ⭕ 맞음 · ❌ 틀림 · 🎯 과녁 · 🎈 물풍선 상자
   (칸은 9개뿐이라 **장르가 필요한 것만 꺼내 줍니다.**)
   이기는 방법 7가지(골인까지 가기 · 다 모으기 · 제일 높이 · 버티기 ·
   퀴즈 다 맞히기 · 숨은 도도 찾기 · 과녁 다 맞히기)에
   제한 시간 · 목숨 · 점프 힘을 정하면 끝입니다.

> **슈팅 게임은 "물풍선 맞히기"로 만들었습니다.** 총도, 맞아서 아픈 표현도
> 넣지 않았습니다. 조준하고 · 던지고 · 맞히고 · 점수가 오르는 재미는 그대로인데,
> 맞는 쪽이 사람이 아니라 🎯 과녁이고 터지는 건 물입니다.
> 던지기는 `E` 또는 `F` 또는 왼쪽 클릭(휴대폰은 🎈 던지기 단추)이고,
> 물풍선도 떨어지기 때문에 먼 과녁은 조금 위를 보고 던져야 맞습니다.
3. **🌷 꾸미기** — 예쁘게 꾸밉니다.

**▶ 해보기** 로 바로 해 보고, 📍 여기서 로 지금 서 있는 자리에서 시작할 수도
있습니다. 아이는 코드를 한 글자도 쓰지 않습니다.

### 🪶 도도AI와 함께 만들기
이 게임의 핵심은 **AI와 함께 게임을 만드는 것**입니다. 그래서 도도AI는
창을 열어야 나오는 기능이 아니라 **스튜디오 왼쪽에 늘 붙어 있습니다.**
(화면이 좁으면 `T` 로 여는 창으로 바뀝니다.)

- **먼저 말을 겁니다.** 시작점이 없으면 "🚩 시작점이 없어!", 다 갖춰지면
  "▶ 해보기 를 눌러 봐" 하고 도도AI가 알려 줍니다. 아이는 *무엇을 물어봐야
  하는지* 모르기 때문입니다.
- "퀴즈 만들어 줘" · "피하기 만들어 줘" · "숨바꼭질 만들어 줘" → 장르가 통째로 바뀌고
  기본 판까지 깔립니다
- "발판 10개 깔아 줘" → 뛰어서 닿는 거리로만 깔아 줍니다
- "여기에 깜빡 함정 놔 줘" · "골인 놔 줘"
- "30초 안에 골인하게 해 줘" · "목숨 3개" · "더 어렵게 해 줘"
- 못 알아들은 말은 그대로 **아이디어 카드**로 갑니다 (섬의 도도AI와 같은 원칙)

### 🟥 로블록스로 가져가기
만든 게임을 **로블록스 장소 파일(`.rbxlx`)** 로 저장할 수 있습니다.
🛠️ 도도 스튜디오 → 내 게임 → **🟥 로블록스로**.
블록 한 칸이 로블록스 블록 4스터드로 바뀌고, 🚩 시작점은 `SpawnLocation`,
🪙 코인과 ☠️ 함정에는 작은 루아 스크립트가 붙습니다.

> 규칙(시간 · 목숨 · 이기는 방법)은 따라가지 않습니다. 그건 로블록스에서
> 루아로 만들어야 합니다.
> 로블록스 계정에 **자동으로 올리는 것**(Open Cloud API)은 API 키를 숨길
> 서버가 있어야 합니다. 키를 이 html 에 넣으면 파일을 연 사람 누구나
> 훔쳐볼 수 있어서 넣지 않았습니다.

### 👫 친구가 내 게임에 참여하기
만든 게임은 `BWG1:...` **게임 코드** 한 덩어리가 됩니다. 카톡으로 보내면
친구가 🛠️ 도도 스튜디오에 붙여넣어 바로 할 수 있습니다. 서버도 로그인도
개인정보도 없습니다.

> **서버가 있어야만 되는 것**은 솔직히 적어 둡니다 — 같은 시간에 함께 뛰는
> 실시간 멀티, 게임 목록·검색·인기 순위, 전체 순위표, 채팅. 이건 서버 없이는
> 안 됩니다.

### 만들고 모으기
- **블록 쌓기·부수기**, 코인·별 모으기, 점프 코스(오비) 3개
- **제작대** — 부순 블록이 재료 주머니에 쌓이고, 그 재료로 특별 블록 3종을 만듭니다.
  통통 블록(밟으면 튀어오름) · 램프(밤에 빛남) · 얼음(미끄러짐)
- **낮과 밤** — 5분에 한 바퀴. 밤에는 별과 달이 뜨고 램프가 켜집니다. 몬스터는 없습니다.
- **배지 28종**, 출석 보상, 레벨·퀘스트·콤보
- 도도 깃털 색 7종(상점) · 펫 3종(아기 도도 · 블록 고양이 · 콩콩 토끼)

### 청사진 건축학교 📐
무엇을 지을지 모를 때, 반투명한 **유령 블록**이 자리를 알려 줍니다.
틀린 블록을 놓으면 "여기는 🪵 나무 자리예요" 라고 알려 주니 따라 지으며 배웁니다.
계단 탑 · 나무 벤치 · 작은 집 · 무지개 다리 4종.

### 되감기 ⏪
실수로 아끼던 블록을 부쉈어도 `Z` 한 번이면 되돌아옵니다. 80번까지.

### 친구와 함께 👫
서버도 로그인도 없이 **코드를 주고받아** 친구가 됩니다.

1. 내 초대 코드를 친구에게 보냅니다 (담기는 건 별명과 무작위 6글자뿐)
2. 친구가 넣으면 친구가 바로 **콩콩 토끼**를 받고 "고마워 코드"가 나옵니다
3. 친구가 그 코드를 나에게 보내 주면 나도 선물 + 친구 1명

친구 3명이면 황금 왕관, 5명이면 별똥별 꼬리를 받습니다.
**월드 코드**로 내가 지은 건축물을 통째로 친구 게임에 옮길 수도 있습니다.

### 내 아이디어가 게임이 된다 💬
"무지개 슬라이드 넣어 주세요!" 라고 쓰면 **아이디어 코드**가 나옵니다.
그 코드를 보내 주면 다음 버전에 실제로 들어가고,
게임 안 **명예의 전당**에 그 아이의 이름이 남습니다.

### 내 섬 꾸미고 자랑하기 🏝️
따로 "내 방"을 만들지 않았습니다. **지금 놀고 있는 이 섬이 곧 내 방**입니다.

- **섬 이름 짓기** — 마을 입구 간판에 그 이름이 실제로 걸립니다.
- **한 번에 꾸미기 10종** — 보고 있는 쪽에 한 번에 지어 줍니다.
  꽃밭 · 분수 · 모닥불 · 무지개 기둥 · 야자수 · 하트 조형물 · 울타리 ·
  가로등 길 · **무지개 미끄럼틀** · **전망대**
  마음에 안 들면 `Z` 한 번으로 **통째로** 사라집니다.
- **자랑 카드 🪪** — 섬 사진 + 배지·레벨·코인·친구 수 + 내 초대 코드를
  900×1200 그림 한 장으로 만들어 저장합니다. 카톡에 그대로 올리면 됩니다.
- **내 섬 코드 🏝️** — 친구가 이 코드를 넣으면 내가 지은 섬을 그대로 구경합니다.
  구경 중에 블록을 놓아도 **친구 자신의 섬은 절대 바뀌지 않습니다**
  (구경 정보는 탭을 닫으면 사라지는 `sessionStorage` 에만 둡니다).

### 녹화 🎥
🎥 단추(또는 `Shift`+`R`)를 누르면 **유튜브 쇼츠 모양 세로 영상(720×1280)** 으로
녹화됩니다. 가로 게임 화면을 그대로 찍는 게 아니라, 세로 화면을 따로 한 장 두고
거기에 게임 화면 + 섬 이름 + 지금 기록 + 해시태그를 같이 그려서 찍습니다.
게임 소리도 함께 담깁니다. 1분이 넘으면 자동으로 멈추고 저장 창이 뜹니다.
📸 로 지금 화면을 사진으로 저장할 수도 있습니다.

### 15초 도전 🎬
짧고 눈에 보이는 도전 4종. 성공하면 배지와 함께 영상 제목을 만들어 주고,
**도전하는 15초를 영상 파일(webm)로 저장**해 줍니다.

## 기술

- Three.js (CDN), 단일 HTML 파일, 인라인 CSS/JS
- 외부 이미지·사운드 파일 없음 — 그래픽은 캔버스로 그리고 소리는 Web Audio로 합성
- 진행 상황은 브라우저 `localStorage`에 저장
