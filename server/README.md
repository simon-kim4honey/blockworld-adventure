# 💬 도도블록 서버

도도블록의 대화창과 🔗 짧은 게임 번호가 쓰는 아주 작은 서버입니다.
파일 하나(`src/worker.js`)가 전부예요.

## 이 서버가 하는 일 / 안 하는 일

**하는 일**
- 💬 방에 말을 쌓아 두고, 새로 온 것만 돌려줍니다.
- 🪶 한 방에서 도도AI 를 맡은 사람이 누구인지 정해 줍니다(같은 대답이 두 번 뜨지 않게).
- 🔗 수백 자짜리 게임 코드를 맡아 두고 **짧은 번호**를 줍니다 (예: `AB12CD3`).

**안 하는 일**
- 회원가입, 로그인, 이름·전화·이메일·나이 받기 — 하나도 없습니다.
- 별명과 아이가 친 말 말고는 아무것도 저장하지 않습니다.

**아이 안전**
아이가 글자를 직접 치기 때문에 서버에서 한 번 더 거릅니다.
게임 안에도 같은 거르개가 있지만, 그 파일을 고쳐서 보내는 사람이 있을 수 있으니
**서버 쪽이 진짜 관문**입니다. 둘은 항상 같이 고쳐야 합니다.

| 막는 것 | 예 |
|---|---|
| 링크 | `http://…`, `www.…`, `.com` |
| 전화번호처럼 긴 숫자 | `010-1234-5678` |
| 욕설 | 금지어 목록 |
| 개인정보 유도 | 카톡·인스타·디엠·주소·이메일·몇반·"무슨 학교야?" |
| 너무 긴 말 | 60자 넘으면 |
| 너무 빠른 연타 | 같은 사람 1.2초에 한 번 |

별명도 따로 거릅니다(숫자 3개 이상 붙으면 막기, 금지어, 길이 10자).

## 올리는 방법 (처음 한 번만)

1. Cloudflare 계정을 만듭니다 — https://dash.cloudflare.com/sign-up (무료)
2. 이 폴더에서 아래를 차례로 칩니다.

```bash
cd server
npm install -g wrangler     # 한 번만
wrangler login              # 브라우저가 열리면 허락을 눌러 주세요
wrangler deploy
```

3. 다 되면 이런 주소가 나옵니다.

```
https://dodoblock-chat.<내계정이름>.workers.dev
```

4. 게임을 열고 💬 대화 단추 → **⚙️ 서버 주소** 에 그 주소를 붙여넣으면 끝입니다.
   (주소는 각자 기기에만 저장되고, 게임 파일에는 안 들어갑니다.)

## 돈이 얼마나 드나

- 하루 10만 번까지 무료입니다. 아이 100명이 매일 놀아도 무료 안에서 끝납니다.
- 더 늘면 한 달 5달러(약 7천 원) 요금제로 올라갑니다.
- 대화 방 하나에 최근 **120개**만 남고 오래된 건 저절로 지워집니다.
  그래서 쌓이는 자료도 계속 작게 유지됩니다.

## 잘 되는지 확인하기

```bash
curl https://dodoblock-chat.<내계정이름>.workers.dev/health
# {"ok":true,"what":"도도블록 대화 서버"}
```

## 방은 어떻게 나뉘나

| 방 이름 | 누가 쓰나 |
|---|---|
| `plaza` | 🏝️ 도도 광장 — 모두가 같이 쓰는 방 |
| `island:AB12CD` | 💌 그 섬 주인의 이야기방. 놀러 온 친구가 말을 남기면 주인이 나중에 봅니다 |

방 이름 규칙에 안 맞으면 서버가 받지 않습니다.

## 🔗 짧은 게임 번호

게임 코드는 게임 내용 자체라서, 서버가 없으면 수백 자를 통째로 들고 다녀야 합니다.
서버가 있으면 내용을 여기 맡겨 두고 **번호만** 주고받으면 됩니다.

번호 = 내 번호 6글자 + 칸 번호 1글자 (예: `AB12CD3`). 한 사람이 9칸까지 쓰고,
열 번째를 맡기면 첫 칸부터 덮어씁니다.

| 하는 일 | 부르는 법 |
|---|---|
| 맡기기 | `POST /g/AB12CD` · 몸통에 코드 → `{"ok":true,"key":"AB12CD3"}` |
| 찾기 | `GET /g/AB12CD3` → `{"ok":true,"code":"BWG2:…"}` |

게임이 인터넷 주소로 열려 있으면 `주소?g=AB12CD3` 링크가 만들어져서,
친구는 그 링크를 누르기만 하면 됩니다. 파일로 열었을 때는 번호만 나옵니다
(친구가 코드 칸에 번호 7글자를 넣으면 돼요).

## 서버 없이도 되나

됩니다. 서버 주소를 안 넣으면 대화창이 **🧪 혼자 시험** 모드로 켜집니다.
같은 컴퓨터에서 창을 두 개 띄우면 서로 말이 오가서, 어떻게 생겼는지
직접 만져 볼 수 있어요. 다른 사람에게는 안 갑니다.
